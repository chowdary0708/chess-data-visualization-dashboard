# Chess Data Visualization Dashboard

## 📊 Project Overview
This project analyzes a chess dataset using Power BI to extract meaningful insights about player ratings, openings, and game outcomes.

## 🛠 Tools Used
- Power BI
- Data Visualization Techniques

## 📁 Files Included
- chess_dashboard.pbix
- Assignment Report (PDF/DOCX)

## 📈 Dashboard Features
- Line Chart: Frequency of openings
- Bar Chart: Average rating by opening
- Column Chart: Rating distribution
- Scatter Plot: Relationship between player type and rating

## 🔍 Insights
- Certain openings are more frequently played
- Ratings mostly fall in mid-range values
- Player performance varies between white and black
